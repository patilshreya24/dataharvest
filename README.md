# DataHarvest 📊
DataHarvest is a modern web application designed to collect, organize, and manage data through a clean and user-friendly interface.

## 🚀 Live Demo
👉 https://dataharvest-vert.vercel.app/

## ✨ Features
- Clean and responsive user interface
- Easy data management and organization
- Interactive web interface
- Responsive design
- Fast and modern frontend
- Deployed and accessible online
  
## 🛠️ Tech Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Vercel
  
## 📂 Project Structure
The project is organized into separate components and directories for better maintainability, including the frontend source code, public assets, and data connection-related files.

## ⚙️ Installation
1. Clone the repository:
   git clone https://github.com/patilshreya24/dataharvest.git
2. Navigate to the project:
   cd dataharvest
3. Install dependencies:
   npm install
4. Start the development server:
   npm run dev
   
## 🌐 Deployment
The application is deployed using Vercel.
Live Application:
https://dataharvest-vert.vercel.app/
